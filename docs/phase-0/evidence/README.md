# Phase 0 evidence

Evidence records what was actually executed or reviewed. It does not copy large generated logs into Git and does not contain secrets or real data.

Each evidence note records:

- date and environment;
- source revision;
- exact command;
- relevant versions;
- result and failures;
- links to tests or artifacts; and
- limits of what the result proves.
